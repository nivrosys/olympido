# Security Policy

At **Nivrosys**, security, data integrity, and compliance are paramount. We take all potential security vulnerabilities seriously.

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in Olympido or any Nivrosys software service, please **do NOT report it via public GitHub issues**. 

Instead, please report it privately to our security team:

* **Email**: [security@nivrosys.com](mailto:security@nivrosys.com) (or [contact@nivrosys.com](mailto:contact@nivrosys.com))
* **Subject**: `[SECURITY VULNERABILITY] - Olympido`

### Please Include:
1. Type of vulnerability and affected component (e.g., Auth, WebSocket gateway, Rating engine, Database).
2. Step-by-step instructions or proof-of-concept to reproduce the issue.
3. Potential impact of the vulnerability.

### Our Commitment:
* **Initial Response**: Within 24-48 business hours.
* **Triage & Remediation**: We will investigate, prepare a fix, and publish a patch in our regular release cycle or an emergency security advisory.
* **Credit**: We will gladly acknowledge your responsible disclosure once the fix is deployed.
